# Objection Handling Library

## Price is too high
1. Acknowledge the budget concern.
2. Reconfirm priority features.
3. Compare alternatives using approved data.
4. Offer lower-price options if available.
5. Never invent discounts.

## I need more time
1. Clarify what information is missing.
2. Offer a concise comparison.
3. Set an agreed follow-up date.
4. Avoid artificial urgency.

## Another project is cheaper
1. Ask what is included in the comparison.
2. Compare price, area, delivery, payment plan, location, and features.
3. Avoid criticizing competitors.
4. Use factual differences only.

## I want a discount
1. Do not promise one.
2. Explain that commercial approvals may be required.
3. Capture the request for salesperson review.
