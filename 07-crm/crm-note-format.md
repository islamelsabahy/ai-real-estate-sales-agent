# CRM Note Format

```text
Lead Status:
Qualification:
Budget:
Location:
Property Type:
Bedrooms:
Purpose:
Timeline:
Payment Preference:
Key Priorities:
Objections:
Units Discussed:
Next Best Action:
Next Follow-Up:
```

Rules:
- Keep notes factual.
- Do not record unnecessary sensitive information.
- Distinguish customer statements from salesperson assumptions.
- Avoid subjective labels.
