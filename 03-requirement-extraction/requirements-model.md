# Requirement Model

## Must-Have Fields

- location
- property_type
- budget_min
- budget_max
- purchase_timeline

## Optional Fields

- bedrooms
- bathrooms
- min_area_sqm
- max_area_sqm
- floor_preference
- view_preference
- delivery_timeline
- payment_plan_preference
- purpose
- finishing
- amenities
- developer_preference
- notes

## Missing Information Strategy

The agent should ask only for fields that materially improve recommendation quality.

Avoid interrogating the user with all fields at once.
