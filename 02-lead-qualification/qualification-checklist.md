# Qualification Checklist

Capture when possible:

- [ ] Name / preferred contact identity
- [ ] Purchase purpose
- [ ] Preferred location
- [ ] Property type
- [ ] Bedrooms / area
- [ ] Budget range
- [ ] Payment preference
- [ ] Purchase timeline
- [ ] Decision-maker status
- [ ] Financing need
- [ ] Source / channel
- [ ] Preferred contact method

Avoid collecting unnecessary sensitive data.
