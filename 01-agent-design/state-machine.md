# Conversation State Machine

Suggested states:

- NEW
- QUALIFYING
- QUALIFIED
- REQUIREMENTS_INCOMPLETE
- MATCHING
- RECOMMENDING
- OBJECTION_HANDLING
- FOLLOW_UP
- CLOSED_WON
- CLOSED_LOST

## Transition Examples

```text
NEW → QUALIFYING
QUALIFYING → QUALIFIED
QUALIFYING → REQUIREMENTS_INCOMPLETE
QUALIFIED → MATCHING
MATCHING → RECOMMENDING
RECOMMENDING → OBJECTION_HANDLING
RECOMMENDING → FOLLOW_UP
FOLLOW_UP → CLOSED_WON / CLOSED_LOST
```

All state changes should be logged in production implementations.
