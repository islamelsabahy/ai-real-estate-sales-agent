# Public Repository Data Policy

This repository must remain safe for public visibility.

## Never Commit

- Real customer names
- Real phone numbers
- National IDs
- Passport data
- Bank details
- Contract documents
- Cheque details or images
- Private broker information
- Employee personal data
- Production CRM exports
- Company-confidential pricing
- Credentials
- API keys
- Tokens
- Private URLs
- Internal company/project names

## Allowed

- Fictional projects
- Fictional units
- Fictional leads
- Synthetic conversations
- Generic business rules
- Generic price examples
